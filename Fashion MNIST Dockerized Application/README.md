# Fashion MNIST Dockerized Application

Dockerized web application for classifying fashion items using the Fashion MNIST dataset.

## Structure
- `app/` - Application code
- `notebooks/` - Training notebooks
- `test_images/` - Sample test images

## Technologies
- TensorFlow/Keras
- Docker
- Python
- Fashion MNIST Dataset

## Usage
1. Build Docker image
2. Run container
3. Access web interface
4. Upload fashion item images for classification
