# Breast Cancer Classification

A deep learning model to classify breast cancer from medical images. 

## Structure
- `Dataset/` - Training and testing data
- `Model/` - Trained model files

## Technologies
- TensorFlow/Keras
- Python
- Jupyter Notebook

## Usage
1. Load the dataset
2. Train the model or use pre-trained model
3. Make predictions on new images
