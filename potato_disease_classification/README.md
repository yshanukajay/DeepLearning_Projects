# Potato Disease Classification

Deep learning application to classify potato plant diseases from leaf images.

## Structure
- `api/` - FastAPI backend
- `frontend/` - Web interface
- `models/` - Trained models
- `notebooks/` - Training notebooks
- `dataset/` - Training data

## Technologies
- TensorFlow/Keras
- FastAPI
- React
- Docker (optional)

## Usage

### Backend
```bash
cd api
python main.py
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## Features
- Upload potato leaf images
- Real-time disease classification
- Confidence scores
