# MNIST Digit Classification

Handwritten digit recognition using the MNIST dataset.

## Structure
- `Model/` - Trained model files
- `Test Image/` - Sample test images

## Technologies
- TensorFlow/Keras
- Python
- MNIST Dataset

## Usage
1. Load the trained model
2. Upload handwritten digit image
3. Get digit prediction
